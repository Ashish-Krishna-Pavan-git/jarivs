# Integrations

## Telegram

Create a bot with BotFather, set `TELEGRAM_TOKEN`, then message the bot:

```text
/start
```

The chat ID is stored as an enabled notification channel. `/stop` disables it.

## Slack

Create a Slack incoming webhook and paste it in Notifications or Admin -> Integrations.

## Multiple Users

JARVIS supports multiple Telegram chat IDs and multiple Slack webhooks/workspaces. Users can manage their own channels; admins can manage all channels.
