# Backend Reports Module

## Purpose
Generates executive intelligence synthesis digests, newsletter publications, and daily briefing reports.

## Contained Modules
- `daily_summary.py`: Cross-cycle daily summary report generator.
- `newsletter_publisher.py`: Newsletter report renderer.

## Dependencies
- `backend.ai.ai_router`, `backend.storage.persistence`, `backend.services.audio_generator`.

## Entry Points
- `run_daily_summary()`: Generates daily executive summary digest.
