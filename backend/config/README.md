# Backend Configuration Module

## Purpose
Centralized configuration parameters, platform detection, default constants, directory path resolutions, and `.env` loader.

## Contained Modules
- `config.py`: System configuration definitions.

## Dependencies
- `python-dotenv`, `os`, `sys`, `pathlib`.

## Entry Points
- `DATA_DIR`, `PROCESSED_DIR`, `DAILY_DIR`, `ARCHIVE_DIR`, `RAW_DIR`, `SEEN_FILE`: Core storage path constants.
